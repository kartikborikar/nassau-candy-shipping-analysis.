# Factory-to-Customer Shipping Route Efficiency Analysis

## Project Overview

This project analyzes the shipping performance of Nassau Candy Distributor using Python.

The objective is to identify shipping trends, delivery performance, regional sales, customer behavior, and business insights to improve shipping efficiency.

---

## Tools Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Plotly

---

## Dataset

- Nassau Candy Distributor Dataset
- CSV Format

---

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Business Insights
6. Conclusion

---

## Key Analysis

- Total Sales
- Monthly Sales
- Regional Sales
- Ship Mode Analysis
- Customer Analysis
- Category Analysis
- Profit Analysis
- Delivery Time Analysis

---

## Conclusion

This project demonstrates how Python can be used to analyze logistics and shipping data for better business decision-making.
